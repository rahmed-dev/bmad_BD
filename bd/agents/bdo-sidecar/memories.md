# BDO Memory: Past Projects

This file stores past project references. BDO reads this on every activation
to personalise proposals and portfolios with real, specific work history.

## Past Projects

*No projects added yet. Use [PP] Past Projects → Add to build your knowledge base.*

---

## Entry Format

When adding projects, use this structure:

### Project: [Short Label]
- **Client type:** [e.g., E-commerce startup, SaaS B2B, Recruitment agency]
- **What was built:** [Brief description of deliverables]
- **Outcome:** [What happened as a result of the work]
- **Results:** [Quantified where possible — e.g., "30% increase in CTR", "ROAS 1.8x → 4.2x"]
- **Skills demonstrated:** [e.g., Shopify, email marketing, Facebook Ads, copywriting]
- **Tags:** [keywords for matching to job posts — e.g., "landing page", "Shopify", "B2B SaaS"]

---

## Usage Notes

- BDO selects the most relevant project entry when writing a proposal
- Entries with quantified results produce stronger proposals
- Add a new entry immediately after completing a project — details are freshest then
- Tags help BDO match the right project to the right job description
